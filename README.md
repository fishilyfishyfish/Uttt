# Uttt

**궁극의 틱택토(Ultimate Tic-Tac-Toe)** 를 알파제로 방식 강화학습으로 처음부터 학습시킨다.
사람이 만든 전략은 하나도 안 넣었고, 신경망이 자기 자신과 두면서 배운다.
깃허브 액션이 알아서 돌리므로 내 기기는 꺼놔도 된다.

## 게임 규칙

3x3 판 안에 3x3 판이 또 있다. 칸은 모두 81개.

- 작은 판은 보통 틱택토처럼 3개를 이으면 먹는다
- 작은 판 3개를 한 줄로 먹으면 최종 승리
- **내가 둔 칸의 위치가 상대가 둬야 할 작은 판을 정한다.** 왼쪽 위 칸에 두면 상대는 왼쪽 위 작은 판에 둬야 한다
- 보내진 작은 판이 이미 끝났으면 아무 데나 둘 수 있다
- 큰 판이 다 찼는데 세 줄이 없으면 작은 판을 더 많이 먹은 쪽이 이긴다
  (순수 무승부로 하려면 `uttt.py` 의 `TIEBREAK_BY_COUNT = False`)

## 시작하기

1. 저장소를 **Public** 으로 만든다 (공개면 액션 실행 시간 제한이 없다)
2. 파일 4개를 올린다. `train.yml` 은 반드시 `.github/workflows/train.yml` 경로로
3. Settings → Actions → General → Workflow permissions 를 **Read and write permissions** 로
4. Actions 탭 → train → **Run workflow**

이후로는 한 번 실행이 끝날 때마다 스스로 다음 실행을 걸어서 계속 돈다.
400회차에 8시간쯤 걸리고, 깃허브 실행 2번이면 끝난다.

## 결과 보기

**`state/REPORT.md`** 하나만 보면 된다. 그래프와 회차별 표가 들어 있다.

| 숫자 | 뜻 | 정상이면 |
|---|---|---|
| **기준 신경망 상대** | 10회차 때 얼려 둔 신경망과의 승률 | **꾸준히 오른다.** 이게 제일 중요함 |
| 휴리스틱 상대 | 작은 판 딸 수 있으면 따고 상대 수는 막는 봇 | 50%를 넘어 올라간다 |
| 무작위 상대 | 아무 데나 두는 상대 | 금방 95% 이상 |
| 이전 버전 상대 | 새로 학습한 신경망 vs 지금 쓰는 신경망 | 55% 넘으면 교체 |
| 정책 손실 | 신경망이 탐색 결과를 얼마나 잘 따라하는지 | **내려간다** |

**정책 손실이 제일 빠른 고장 신호다.** 회차가 가는데 안 내려가면 탐색이 신경망보다
못하다는 뜻이고, 그러면 배울 게 없어서 학습이 멈춘다. 그때는 `sims` 를 올려야 한다.

## 멈추기

`state/STOP` 이라는 빈 파일을 만들어 커밋하면 다음 실행을 걸지 않는다.
다시 돌리려면 지우고 Run workflow. 다 끝나면 `state/DONE` 이 생기고 스스로 멈춘다.

## 설정 (`config.json`)

| 항목 | 뜻 |
|---|---|
| `sims` | 자기대국에서 한 수를 정할 때 탐색하는 횟수. 이 게임은 고를 수가 9개 이하라 400이면 충분하다 |
| `eval_sims` | 실력 잴 때 쓰는 탐색 횟수 (싸게 하려고 낮춤) |
| `games_per_iter` | 한 회차에 둘 자기대국 판수 |
| `arena_games` | 새 신경망과 지금 신경망을 몇 판 붙일지. 적으면 교체가 운으로 결정된다 |
| `promote_winrate` | 이 승률을 넘으면 교체 |
| `anchor_at` | 몇 회차 신경망을 '기준점'으로 얼려 둘지 |
| `max_minutes` | 한 실행에서 돌릴 시간. 액션 제한(6시간)보다 짧게 |

## 직접 돌려보기

```bash
pip install -r requirements.txt
python uttt.py --config config-smoke.json   # 몇 분이면 한 바퀴 (제대로 도는지만 확인)
python uttt.py --config config.json         # 본 실행
```

## 코드

`uttt.py` 파일 하나에 규칙, 신경망, MCTS, 자기대국, 학습, 성적표가 다 들어 있다.
약 400줄. 구역별로 주석이 달려 있다.

- 상태는 항상 **둘 차례인 사람 기준**으로 뒤집어서 들고 다닌다. 그래서 "누구 차례인지"를
  신경망 입력에 따로 넣을 필요가 없다
- 신경망 입력 199개: 내 돌 81 + 상대 돌 81 + 작은 판 상태 27 + 보내진 판 10
- 가치는 이기면 +1, 비기면 0, 지면 -1
